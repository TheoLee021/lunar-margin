# 회사별 공개 조건 가격 비교

대상은 Blue Origin, ispace-U.S., SpaceX, Lockheed Martin Space, Northrop Grumman
Space Systems, Voyager Technologies 여섯 회사다. 발사체 제작사와 달 배송 서비스
판매자를 구분한다. 예를 들어 Voyager Griffin-1의 발사체가 SpaceX Falcon Heavy라는
이유로 같은 배송을 SpaceX 견적으로 중복 등록하지 않는다.

## 공개 자료와 미정 상태

버전 관리되는 `api/src/lunar_margin/provider_catalog.json`이 출처, 발표일, 확인일,
일정의 정확도와 공개된 조건을 보관한다. 화면 요청마다 외부 웹사이트를 다시 조회하지
않는다. 자료 갱신 후에는 API를 재시작한다. NASA 선정 자격이나 임무 계약 총액을
특정 날짜의 판매 가능한 화물 견적으로 해석하지 않는다.

- Blue Origin MK1: 기체 적재 상한 3,000kg과 VIPER 임무 정보를 확인했다.
  정확한 출발·착륙일, 잔여 적재량, 판매 요금은 미정으로 보관한다.
- ispace-U.S.: Team Draper/APEX 임무의 2027년 이전 불가 발표를 기록한다.
  미국 임무와 일본 ULTRA 임무의 일정을 합치지 않는다.
- SpaceX: 달 표면 화물 서비스의 2028년 이전 불가 및 $100M/metric ton 안내를
  $100,000/kg으로 환산해 기록한다. 최소 청구량·청구 단위·고정비와 정확한 운항일이
  확인되지 않았으므로 24kg을 단순 비례해 예약 가능한 총액으로 표시하지 않는다.
- Lockheed Martin, Northrop Grumman: 공급자 선정 출처는 기록하지만 구체 운항편과
  단가가 등록되지 않은 상태를 유지한다.
- Voyager: 2026-11-12 회사 발표의 Griffin-1 2027년 1월 계획을 우선한다.
  2028년 상업 화물 임무 발표도 표시하며, 날짜·가격·잔여 용량을 임의로 채우지 않는다.

모든 숫자는 공급자가 공개한 상한과 실제 판매 가능한 잔여량을 구분한다.
월·연도·NET 정보는 하루 단위 예약 가능 판정이 아니다. 현재 등록된 자료에는
완전한 날짜별 견적이 없어 2027년 날짜 표가 **공개 견적 없음**을 보이는 것이 정상이다.
이는 환경 조건에 적합한 격자가 없다는 뜻이 아니다. 회사별 상세와 공식 출처는 남는다.

## 판정과 계산 순서

1. 출발일·착륙일, 기존 전이 3~150일, 공개된 배송 방식·용량·잔여량·배송 범위,
   단가·고정비·최소 청구량·청구 단위를 확인한다. 필수 미정 항목은 최저가에서 제외한다.
2. 완전한 공개 조건이 있는 편에만 지형 계수를 적용한다. 같은 날짜의 지형은 한 번
   읽으며, 회사별로 DEM이나 SPICE를 재실행하지 않는다.
3. 청구 질량은 공개된 최소 질량과 청구 단위에 맞춰 올림한다. Decimal 연산으로
   0.14kg/0.01kg 같은 소수 청구가 15단위로 잘못 올림되는 것을 방지한다.
4. `고정비 + 공개 kg당 단가 × 청구 질량 × 목적지 계수`로 각 격자 가격을 비교한다.
   목적지 계수는 기존 경사 모델이며, 경합도는 미산정 1.00이다. 공개 단가 기반의
   모델 추정이고 실제 예약·계약 견적은 아니다. 지형 미산정의 1.10 fallback도 표시한다.
5. 각 격자의 최저가를 먼저 구한 뒤 산술평균한다. **회사별 평균 중 최솟값**과 다르다.
   원래 적합한 500m 가격 대상 격자를 모두 유지하며 TOP 100이나 화면 범위로 줄이지 않는다.
6. 일부 격자만 견적이 있으면 전체 평균을 만들지 않고 `partial_coverage`와 산정 개수를
   표시한다. 견적 없는 격자를 0원으로 채우거나 평균 분모에서 조용히 제거하지 않는다.

## 성능 확인

로컬 개발 환경에서 측정한 값이며 서버 환경의 보장 시간은 아니다.

| 측정 | 범위 | 결과 |
| --- | --- | --- |
| 공개 카탈로그 API | 5개 착륙일 × 5개 출발일, 완전한 공개 편이 없는 현재 자료 | 0.0014–0.0093초 |
| 합성 최악 조건 가격 비교 | 공개 조건을 충족한 6개 회사 × 142,642개 격자 × 5일 | 0.0037–0.0056초 |

두 번째 측정은 테스트용 합성 단가와 일정으로 **가격 비교 연산만** 실행했다.
실제 회사 가격이나 새 날짜의 NASA 분석 시간으로 제시하지 않는다. 환경 분석과
지형 계수 산정은 별도이며, 회사 수가 늘어도 그 작업을 6번 반복하지 않는다.

검사는 110개 서로 다른 fine 격자(선정 후보는 1개)와 coarse 격자를 포함한 API 사례,
회사별 최저가가 격자에 따라 달라지는 사례, 부분 배송 범위, 공개 자료 미정 상태,
회사 규정의 용량·일정·배송 방식·소수 청구 단위와 UI 오류 복구를 다룬다.
