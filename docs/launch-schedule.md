# 전체 발사 일정과 데모 예상 비용

데모 화면은 Spaceflight Now의 전체 upcoming feed와 Space Launch Schedule의 전체
예정 목록을 목적지·회사 제한 없이 읽는다. 일반 위성·군사·통신 발사도 포함하며 ULA 등
기존 6개 회사 밖의 발사사는 기타 발사사로 조회한다. 현재 확인된 일정은 185개다.
추가로 달 프로그램 검색 색인을 끝 페이지까지 읽어 기본 목록에 없는 미정 임무를 보완한다.
완료·취소·실패한 과거 임무는 제외한다. 같은 이름을 가진 별개 발사는 소스 ID로 유지한다.

출발일은 **달 임무 분석용 데모 가정**으로 선택한다. 실제 임무가 달로 가거나 고객 화물을
실을 수 있다는 의미가 아니다. UI는 실제 발사사, 달 관련/일반 발사, 출처·정확도를 표시한다.
착륙일은 사용자가 별도로 선택하며 발사일을 적용해도 바뀌지 않는다. 가격은 기존 6개 회사
모델 비교를 유지하며, 발사 목록에 추가된 업체의 실제 운임으로 해석하지 않는다.

SLS 전체 목록의 모든 페이지에서 기록 ID와 날짜·정확도·발사사 정보를 읽고 공개
WordPress API로 임무 설명을 일괄 조회한다. 일반 발사는 이미 받은 목록 카드에서
날짜를 파싱하므로 임무마다 상세 페이지를 재다운로드하지 않는다. 목록 밖 달 프로그램
항목만 상세 페이지를 읽는다. 모든 페이지를 읽지 못하면 complete=false와 마지막 확인
자료를 반환한다. 소스별 검사한 기록·페이지 수와 확인 시각을 제공하고 최대 10분 재사용한다.
외부 요청은 각각 5초·4MB로 제한하며 페이지 한도를 넘으면 완료로 보고하지 않는다.

`GET /pricing/providers/launches`의 scope는 all_launches_demo다. 기존 6개 회사와 직접
연결되지 않은 발사는 provider_id=null이며 launch_provider에 실제 발사사를 보관한다.
날짜 선택 가능 여부는 departure_date로 구분하고 월·분기·연도·TBD를 임의의 일자로 만들지
않는다. 모든 날짜는 UTC다. 예를 들어 USSF-317의 11월 17일 저녁 PST 표기는 UTC로
11월 18일이다. [원본 임무](https://www.spacelaunchschedule.com/launch/falcon-9-block-5-ussf-317/).

SLS의 표시문만 보면 연도 정보가 12월로 보이는 경우가 있어 HTML의 data-precision을
우선한다. [정확도 원본 정의](https://ll.thespacedevs.com/2.2.0/config/netprecision/?format=api&limit=10&offset=10)에서
14는 연도, 7은 월, 8~11은 분기다. 시간 정확도가 있는 항목은 UTC 날짜로 선택할 수 있다.
발사체·착륙선·본문 관련 언급을 구분하며 과거 취소 계약을 현재 배송 회사로 연결하지 않는다.
관련 언급은 참여 확약이 아니며 여러 회사가 관련된 임무는 역할별로 함께 표시될 수 있다.

가격 요청은 `estimate: true`로 모델 모드를 선택한다. 기존 엄격한 공개 견적 API 모드는
기본값으로 유지한다. 회사 공개 단가가 있으면 우선 사용하고, 없으면 기존 배송 방식별
공통 참조 단가(궤도 $300,000/kg, 표면 $1,200,000/kg, 로버 배송 $4,500,000/kg)를 쓴다.
공통 참조 단가의 출처는 기존 Astrobotic PUG이며 각 회사가 제시한 단가라는 뜻이 아니다.
고정비 미공개 시 기존 모델값 $500,000을 적용한다. 청구 규칙이 미공개이면 입력 질량에
비례한다고 가정하고 그 사실을 함께 반환한다. 공개된 청구 규칙은 그대로 적용한다.

`예상 비용 = 고정비 + 적용 단가 × 청구 질량 × 목적지 계수 × 경합도(현재 1.00)`

미공개 용량·배송 범위·운항 여부는 가정으로 공개하며 모델 계산을 막지 않는다. 다만
명시된 용량 초과, 배송 방식 미지원, 공개된 일정 범위 밖, 전이 3~150일 위반, 착륙 지형
부적합은 계속 제외한다. 공개 견적의 `price_usd`와 모델의 `estimate_usd`는 별도 필드다.
후보 상세는 6개 회사 모두 표시하며 같은 공통 모델을 사용하면 같은 가격이 나올 수 있다.
날짜표는 기존 적합 500m 격자 전체에서 회사별 최저 예상 비용을 먼저 구한 뒤 평균한다.
TOP 100으로 표본을 줄이지 않는다. 일부 격자만 산정되면 전체 평균을 만들지 않는다.

실제 저장 실행 `m-4c14300da4`와 같은 조건으로 5개 착륙일(2027-01-08~12)을 조회한
로컬 가격 API 응답은 약 0.17초였다. 저장된 환경 분석과 지형 계수를 재사용한 측정이며
새 날짜의 환경 분석 소요 시간이나 배포 서버의 응답 시간을 보장하지 않는다.
