# 발사 일정과 모델 예상 비용

출발일 선택은 Spaceflight Now의 공개 upcoming feed와 Space Launch Schedule의 전체
예정 목록·달 임무 검색 색인을 읽는다. 두 개 임무의 허용 목록은 사용하지 않는다.
SLS 예정 목록의 모든 페이지에서 기록 ID를 모으고, 공개 WordPress API로 임무 설명을
일괄 조회한다. 달·lunar·Artemis·Gateway·착륙선 프로그램 검색도 끝 페이지까지 읽어
기본 예정 목록에 빠진 미정 임무를 보완한다. 모든 페이지를 읽지 못하면 전체 수집
완료로 표시하지 않고, 마지막으로 완전히 확인한 자료와 원래 시각을 반환한다.

`GET /pricing/providers/launches`는 UTC 날짜, NET/TBD, 출처별 원래 날짜 표현과
정확도, 역할별 관련 회사, 확인 시각, 검사한 기록 수·페이지 수·완료 여부를 반환한다.
서버는 소스별 수집을 병렬로 실행하고 결과를 최대 10분 재사용한다. 외부 요청은
각각 5초·4MB로 제한하며 페이지 안전 한도를 넘으면 수집 미완료로 처리한다.
브라우저는 타사 사이트를 직접 요청하지 않는다. 취소·실패·완료된 과거 임무는 제외한다.

6개 회사는 UI에서 항상 조회할 수 있다. 출처에서 관련 일정을 확인하지 못한 회사는
그 상태를 표시하며 임의로 운항편을 만들지 않는다. 발사체·착륙선·본문 관련 언급을
구분한다. 예를 들어 Griffin의 배송 회사는 Voyager이고 SpaceX는 발사체 회사다.
취소된 과거 계약에만 등장하는 회사를 현재 배송 회사로 연결하지 않는다. 본문의
관련 언급은 참여 확약을 뜻하지 않으며 예약 가능한 화물 운항편으로 해석하지 않는다.

현재 확인한 고유 임무는 10개다. Griffin, Astrobotic 후속편, Blue Moon Pathfinder와
VIPER, Blue Ghost, Nova-C, 터키 달 탐사선, Artemis/HLS 시험 일정 등이 포함된다.
목록은 6개 회사별로 조회하며 여러 회사가 관련된 임무는 각 역할 아래 함께 표시된다.
정확한 날짜가 있는 항목만 출발일에 적용하고 월·분기·연도·TBD는 미정 상태로 읽는다.
출발일 선택은 착륙일을 변경하지 않는다. 착륙일과 임무 기간은 사용자의 환경 분석
시나리오이며 실제 임무의 도착을 보장하지 않는다. 기준일 ±2일 표도 비교용이다.

SLS의 날짜 표시문만 보면 연도 정보가 12월로 보이는 경우가 있다. HTML의
`data-precision`을 우선하여 월말·자정 placeholder를 실제 날짜로 사용하지 않는다.
정확도 코드의 의미는 [원본 LL2 정의](https://ll.thespacedevs.com/2.2.0/config/netprecision/?format=api&limit=10&offset=10)를 따른다.
예를 들어 14는 연도, 7은 월, 8~11은 분기다. 이는 정확도 형식의 참고 자료이며
운항 일정 자체는 사용자가 지정한 두 사이트에서만 수집한다.

가격 요청은 `estimate: true`로 모델 모드를 선택한다. 기존 엄격한 공개 견적 API 모드는
기본값으로 유지한다. 회사 공개 단가가 있으면 우선 사용하고, 없으면 기존 배송 방식별
공통 참조 단가(궤도 $300,000/kg, 표면 $1,200,000/kg, 로버 배송 $4,500,000/kg)를 쓴다.
공통 참조 단가의 출처는 기존 Astrobotic PUG이며 각 회사가 제시한 단가라는 뜻이 아니다.
고정비 미공개 시 기존 모델값 $500,000을 적용한다. 청구 규칙이 미공개이면 입력 질량에
비례한다고 가정하고 그 사실을 함께 반환한다. 공개된 청구 규칙은 그대로 적용한다.

`예상 비용 = 고정비 + 적용 단가 × 청구 질량 × 목적지 계수 × 경합도(현재 1.00)`

미공개 용량·배송 범위·운항 여부는 가정으로 공개하며 모델 계산을 막지 않는다. 다만
명시된 용량 초과, 배송 방식 미지원, 공개된 일정 범위 밖, 전이 3~150일 위반, 착륙 지형
부적합은 계속 제외한다. 공개 견적의 `price_usd`와 모델의 `estimate_usd`는 별도 필드다.
후보 상세는 6개 회사 모두 표시하며 같은 공통 모델을 사용하면 같은 가격이 나올 수 있다.
날짜표는 기존 적합 500m 격자 전체에서 회사별 최저 예상 비용을 먼저 구한 뒤 평균한다.
TOP 100으로 표본을 줄이지 않는다. 일부 격자만 산정되면 전체 평균을 만들지 않는다.

실제 저장 실행 `m-4c14300da4`와 같은 조건으로 5개 착륙일(2027-01-08~12)을 조회한
로컬 가격 API 응답은 약 0.17초였다. 저장된 환경 분석과 지형 계수를 재사용한 측정이며
새 날짜의 환경 분석 소요 시간이나 배포 서버의 응답 시간을 보장하지 않는다.
