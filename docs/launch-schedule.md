# 발사 일정과 모델 예상 비용

출발일 선택은 Spaceflight Now의 공개 upcoming feed와 Space Launch Schedule의 임무
페이지를 서버에서 읽는다. `GET /pricing/providers/launches`는 UTC 날짜, NET/TBD 상태,
출처별 원래 날짜 표현, 마지막 확인 시각과 갱신 실패 여부를 반환한다. 서버는 세 요청을
병렬로 실행하고 결과를 10분 동안 재사용한다. 외부 요청은 각각 5초·4MB로 제한한다.
외부 오류 시 버전 관리된 마지막 확인 자료와 원래 확인 시각을 반환하고 `stale`로 표시한다.
브라우저에서 타사 사이트를 직접 요청하거나 비밀 키를 사용하지 않는다.

현재 연결한 임무는 Griffin Mission One과 Blue Moon Pathfinder다. 발사체 회사와
배송 판매자를 분리해 Griffin은 Voyager로 연결한다. 새로운 임무는
`engine/launch_schedule.py`의 명시적 임무 목록에 추가한다. 모든 로켓 발사를 달 배송편으로
간주하거나 Pathfinder를 VIPER 임무로 합치지 않는다.

현재 Griffin의 출처별 표기는 SFN `NET January 2027`, SLS `Jan 6, 2027 / TBD`다.
합쳐서 2027-01-06을 **잠정 출발일**로 선택할 수 있다. Blue Moon Pathfinder는 월 단위여서
일자가 확정된 선택 항목으로 제공하지 않는다. JSON-LD의 월말·자정 표기를 그대로 쓰지
않고 화면 날짜 표현의 정확도를 확인한다. 서로 다른 일자가 있으면 자동 선택을 막는다.
출발 임무 선택은 착륙일을 변경하지 않는다. 착륙일과 임무 기간은 사용자의 환경 분석
시나리오이며 실제 임무의 도착 일정을 보장하지 않는다. 기준일 ±2일 표도 비교용 시나리오다.

가격 요청은 `estimate: true`로 모델 모드를 선택한다. 기존 엄격한 공개 견적 API 모드는
기본값으로 유지한다. 회사 공개 단가가 있으면 우선 사용하고, 없으면 기존 배송 방식별
공통 참조 단가(궤도 $300,000/kg, 표면 $1,200,000/kg, 로버 배송 $4,500,000/kg)를 쓴다.
공통 참조 단가의 출처는 기존 Astrobotic PUG이며 각 회사가 제시한 단가라는 뜻이 아니다.
고정비 미공개 시 기존 모델값 $500,000을 적용한다. 청구 규칙이 미공개이면 입력 질량에
비례한다고 가정하고 그 사실을 함께 반환한다. 공개된 청구 규칙은 그대로 적용한다.

`예상 비용 = 고정비 + 적용 단가 × 청구 질량 × 목적지 계수 × 경합도(현재 1.00)`

미공개 용량·배송 범위·운항 여부는 가정으로 공개하며 모델 계산을 막지 않는다. 다만
명시된 용량 초과, 배송 방식 미지원, 공개된 일정 범위 밖, 전이 3~150일 위반, 착륙 지형
부적합은 계속 제외한다. 공개 견적의 `price_usd`와 모델의 `estimate_usd`는 별도 필드다.
후보 상세는 6개 회사 모두 표시하며 같은 공통 모델을 사용하면 같은 가격이 나올 수 있다.
날짜표는 기존 적합 500m 격자 전체에서 회사별 최저 예상 비용을 먼저 구한 뒤 평균한다.
TOP 100으로 표본을 줄이지 않는다. 일부 격자만 산정되면 전체 평균을 만들지 않는다.

실제 저장 실행 `m-4c14300da4`와 같은 조건으로 5개 착륙일(2027-01-08~12)을 조회한
로컬 가격 API 응답은 약 0.17초였다. 저장된 환경 분석과 지형 계수를 재사용한 측정이며
새 날짜의 환경 분석 소요 시간이나 배포 서버의 응답 시간을 보장하지 않는다.
